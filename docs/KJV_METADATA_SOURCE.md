# Chapter metadata

Only book/chapter verse counts are retained, not verse text. Derived from https://github.com/aruljohn/Bible-kjv/tree/a9aa4e55afbb3e095f57e4b14cd1f22c5ee8d7c9 . All 66 books, 1,189 sequential chapters and sequential verse indices were validated during generation. KJV numbering is explicitly labeled; other translations may omit or renumber verses.
